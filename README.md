# Direct Urca: three-paper research report

Traditional Chinese, 16:9 HTML presentation summarizing three connected neutron-star
direct-Urca studies and the current BSk24 pairing/PBF emission-regime analysis.

## View

Open the GitHub Pages URL for the repository. Keyboard controls:

- Left/Right, Page Up/Page Down, or Space: navigate slides.
- `N`: toggle speaker notes.
- `F`: toggle full screen.
- Home/End: first or last slide.

## Scientific scope

The pairing/PBF phase map is a conditional, instantaneous core-neutrino luminosity
diagnostic. It is not a full stellar cooling phase diagram. Control-function splicing,
the low-temperature convergence discrepancy, and the PBF prescription remain open
validation gates.

## Contents

Only the self-contained presentation and its referenced figures are published here.
The EOS tables, simulation code, intermediate ledgers, and unpublished project files
are not included.
